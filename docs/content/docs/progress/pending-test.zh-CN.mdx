# 待测试

- 本轮收尾：画布图片节点右键「生成历史」应能查看并恢复最近几次结果；「我的画布」卡片应显示封面缩略图；首页背景图加载正常（WebP）；桌面版启动时页面加载失败应显示错误页而不是白屏；各页面正常加载（vendor 分包后）。
- 画布列表与状态：我的画布支持搜索和排序（最近更新/最近创建/名称）；画布顶栏应显示 ComfyUI 在线状态（在线/离线/检测中/未配置，点击跳转配置）以及「保存中…/已保存」提示；删除提示词库残留后各页面应正常加载（按路由懒加载）。
- 画布快捷键教程：顶栏键盘按钮和画布菜单里的「快捷键」应打开分组教程弹窗，分别列出画布导航（滚轮缩放、缩放滑杆、中键拖动、双指捏合、Ctrl/空格临时切换工具）、选择与编辑（框选、Shift 追加选择、全选、复制粘贴、撤销重做、删除、Esc）、节点操作（方向键微调、Shift 快速微调、Alt 关闭吸附、双击创建、右键菜单、双击图片/文本/标题、组折叠）和其他操作（拖入素材、拖动画布）。
- 画布增强：撤销历史应支持 200 步；选中节点后方向键可微调（Shift 加速）；右键可锁定/解锁节点，锁定节点不可拖动/删除/缩放；拖动时显示并吸附对齐辅助线（Alt 关闭）；多选右键可左/中/右/顶/中/底对齐和等距分布；组节点可折叠/展开；顶栏菜单可导出画布 PNG、切换其他画布；后台生成完成/失败应弹出浏览器通知（需授权）；触屏双指可缩放；文本节点包含 Markdown 语法时按标题/列表/代码/粗体渲染；缩放后双击画布的创建菜单应保持屏幕尺寸并对齐双击位置。
- 我的资产：支持文本/图片/视频/音频；视频卡片显示首帧、可编辑元数据；可多选批量删除/导出/加标签；支持标签筛选、排序、创建时间、拖拽上传；重复文件应提示并跳过；资产卡片可「插入画布」并在画布中生成对应节点；从画布保存的资产可跳回来源画布；画布节点上传的素材应自动出现在「我的资产」。
- Windows 桌面发版：推送与 `VERSION` 以及 `desktop`、`web` 的 package 清单和 npm 锁文件完全一致且格式为 `v<主版本>.<次版本>.<补丁版本>` 的 tag 后，应在 `windows-latest` 从干净检出完成画布前端和安装包构建，并把 `.exe`、`.blockmap`、`latest.yml` 发布到对应 GitHub Release；版本不一致、不是最近合法 tag 的严格下一版本时应在构建前失败，没有旧 tag 时只允许 `v0.0.1`。安装 v0.0.1 后无需另行安装 Bun、Node.js 或 Git 即可启动；本机与局域网 ComfyUI 无需 CORS 参数即可访问，公网地址不得借用桌面本地代理，本地服务返回的 HTML 或脚本不得作为画布同源内容执行；更新到下一个允许版本后本地画布和配置应保留。
- 核心画布精简：顶部导航只保留「我的画布」「我的资产」「配置」；首页只显示核心画布介绍与打开画布按钮，不再出现案例展示；生图工作台、视频工作台、提示词库、文档、GitHub 和版本入口均不可见且对应旧路由不可访问；画布侧栏只保留元素与资产，节点输入区不再显示提示词库，配置页不再显示提示词来源。
- 首页品牌视觉：首页应使用原创深色艺术背景，中心标题和按钮区域保持清晰可读，不受左右画面细节干扰；顶部导航和浏览器标签应显示新的无限连接画布图标，浅色与深色导航背景下均保持清楚。
- 画布独立上传：打开「选择节点」菜单后，应在普通节点列表下方看到独立的「上传图片」「上传视频」「上传音频」；每项只能选择对应类型但允许多选，上传后应在菜单所在位置附近直接创建有内容的素材节点，不自动打开或触发生成面板；空图片、视频、音频生成节点及已有媒体节点的悬浮工具条不应再显示上传或替换入口，底部工具栏的独立通用上传按钮仍可导入三类素材。
- 画布选择与平移：左下工具栏应能切换「选择」与「移动」模式并用图标显示当前模式；选择模式拖动空白区域应显示疏朗清晰的虚线框，虚线长度、间距和粗细在任意缩放比例下保持一致；移动模式应能从空白区域或节点上拖动画布。按住 Control 或空格应临时反转当前工具且不改变工具栏模式，即选择变移动、移动变范围选择；点击画布页任意按钮后按空格应只临时切换工具，不得再次触发该按钮；输入框和可编辑文本内仍可正常输入空格。中键平移以及 Shift/Cmd 追加选择节点应继续可用。
- 文档站国际化：访问文档站首页及 `/docs` 应默认显示英文，切换简体中文后 URL 应带 `/zh-CN` 且首页、顶部导航、侧边栏、正文、搜索框和页面操作文案均显示中文；刷新、站内跳转和再次切回 English 后语言应保持正确，搜索结果与 Markdown/LLM 文档内容不得混入另一种语言。
- 国际化基础框架：从页面右上角切换简体中文或 English 后，首页、顶部及移动端导航、配置主面板、渠道编辑、模型选择、页面标题、页面描述和 Ant Design 内置文案应立即切换，刷新页面后保持所选语言；偏好设置中不应再显示语言选项，其他尚未接入翻译的业务模块暂时仍可能显示中文。
- 全局弹层主题：全站 Dropdown、Menu、Select、Cascader、TreeSelect 等弹层在浅色主题下应使用白色背景、轻灰悬停和选中态，在深色主题下应使用深色背景与低对比度浅色交互态，不应再出现默认黑灰色块、文字对比不足或单个页面配色不一致。
- 画布节点缩放稳定性：选中任意节点并反复拖动四角缩放时，节点工具条应在缩放期间隐藏、松开后恢复，页面不应再出现 `Maximum update depth exceeded`。
- 画布文本复制：在节点信息详情中用鼠标选中文字后，按 `Ctrl/Cmd + C` 应复制所选文本，不应触发画布节点复制；未选中文字且焦点位于画布时，原有节点复制快捷键应保持可用。
- 画布文本设置：文本节点和生成配置节点切换到文本模式后应显示推理强度设置，可选择自动、低、中、高、极高；选择自动时默认 OpenAI Responses 请求不应携带 `reasoning`，选择其他档位时应携带所选强度，刷新画布后节点设置应保留。
- ComfyUI 视频参考资产：为绑定了 API 工作流的视频模型连接图片、视频和音频节点后，固定工作流调用器应分别上传各类素材；只连接部分素材时仅填入实际参与本次生成的槽位，顺序保持一致，未使用的加载节点应移除。
- ComfyUI MiniMax-H3 工作流执行：配置实际 ComfyUI 地址并启用跨域、上传自己的 API 工作流并完成映射后，固定调用器应能上传画布连接的最多 9 张图、3 个视频和 3 个独立音频；未连接槽位不得引用工作流中的占位文件，视频自身音轨应继续连接到映射的视频音频参考输入，完成后应从用户映射的输出节点下载视频并写回画布。
- 本地服务快捷接入：配置页应能一键添加 ComfyUI 并自动填入 8188 地址；点击「添加工作流」可输入名称、选择图片/视频/音频类型，并在该工作流上导入 API 格式 JSON；“测试连接”对 ComfyUI 应检查 `/system_stats`；ComfyUI 编辑页只显示渠道名称、接口地址和工作流列表，不显示协议和 API Key；配置页不再提供新增云端 API 渠道入口，已保存的旧渠道仍可编辑或删除。
- ComfyUI 工作流自助导入：在 ComfyUI 渠道的图片、视频或音频模型行应看到「上传 API 工作流」；导入 API 格式 JSON 后应自动识别并允许调整提示词、时长、比例、兆像素、随机种子、图片/视频/音频槽位和输出节点，显示识别字段、各类槽位数量及缺失必要位置。MiniMax-H3 工作流应能沿节点连线识别 PrimitiveStringMultiline 提示词和经表达式连接的 PrimitiveFloat 秒数，并按 Conditioning 中的编号保持 9 图、3 视频、3 音频顺序；必要位置未映射或 JSON 引用不存在节点时不得保存。「检查当前 ComfyUI」应通过标准 `/object_info` 接口列出缺失节点，适用于官方版、源码版、桌面版和不同整合包，同时明确模型/VAE/CLIP/LoRA 文件不在检查范围内。保存后重新打开配置映射应仍然存在；从画布生成时应由固定调用器按当前连线顺序填槽并删除未使用加载节点，解除映射时同步删除本地工作流，未绑定工作流时应明确提示先上传工作流。
- 画布节点键盘删除：选中任意类型节点后，即使刚点击过节点内非编辑按钮，按 Backspace 或 Delete 也应删除节点且不会触发浏览器返回；输入框、文本域、可编辑文本、弹窗和下拉菜单获得焦点时，应保留原有键盘输入并且不能误删画布节点。
- ComfyUI 后端任务取消：使用用户导入的 ComfyUI 工作流开始生成后点击暂停，画布应停止等待，同时按 prompt ID 取消 ComfyUI 中对应的排队或运行任务；新版接口不可用时应兼容旧版队列删除和中断接口，并且不得因为取消一个任务而误停另一个正在运行的工作流。
- 画布生成前检查：普通生成节点的检查图标和生成配置节点的「检查」按钮应打开预览，准确显示本次最终提示词、渠道、模型、参数、结果位置，以及按实际发送顺序排列的图片、视频、音频和文本参考；绑定 ComfyUI 工作流时应显示各类槽位用量和输出节点，参考素材超量或本地工作流映射丢失时禁止确认生成，检查通过后点击「确认并开始生成」应继续使用原有生成流程。
- 本地仓库一键更新：使用 `bun run dev` 启动画布后，页面及画布右上角应显示云下载更新图标；位于 `main` 分支且工作区干净时，点击后应固定从 `kiligsqsq-ctrl/infinite-canvas-comfyui` 仓库的 `main` 分支仅快进更新并自动刷新，已经最新时应提示无需更新；存在未提交/未跟踪源码、本地与远程分叉、不是 Git 仓库或本地更新服务不可用时应给出对应提示，且不得强制覆盖文件。
- 视频比例与时长设置：任意视频模型的设置面板应只显示 `1:1`、`2:3`、`3:2`、`3:4`、`4:3`、`9:16`、`16:9`、`21:9` 比例，不再显示横屏、竖屏等名称，并保留可直接编辑的 W/H 宽高；秒数快捷项应只有 5s、10s、15s，同时保留自定义秒数输入。选择 MiniMax-H3 时顶部应额外显示 0.4 MP 和 0.9 MP，比例卡片下显示按 32 倍数计算的实际分辨率，例如 0.4 MP + 16:9 为 864×480、0.9 MP + 16:9 为 1280×736；切换其他模型后两个 MP 档位应隐藏。导入映射的 H3 工作流应收到兆像素、比例、自定义宽高和自定义时长，自定义宽高时不再使用 ResolutionSelector 输出。
- 画布组装提示词：输入或连接超长提示词后，浮层正文高度不应继续撑大，内容应可在正文区域内滚动查看和编辑，标题及关闭按钮保持可见。
- 画布节点提示词：图片等节点下方的提示词超过输入区域高度后，鼠标悬停在输入区域内滚动应查看提示词内容，不应缩放画布。
- 画布节点提示词回显：单图或多图生成完成后，切换选择生成结果的根节点及任一子节点，下方输入区域都应继续显示生成时的提示词；切换到其他节点再选回来后也不应清空。
- 画布生成配置：连接文本节点后连续点击生成（包含失败重试），组装提示词不应重复追加上游文本；在生图、文本、视频、音频之间切换时，实际请求应始终使用当前面板展示的对应类型模型。
- 画布多图生成：开始生成 N 张图片后应立即创建一个包含 N 个可展开槽位的图片节点，并且来源到结果只保留一条连线；生成期间空槽位应独立显示生成中或失败，任何已有图片内容的槽位都必须始终显示图片，任意图片率先成功后应立即成为主图并展示，不等待其他请求完成；收起状态应最多显示三层紧密错开的背板，避免占用过多画布空间，右上角应显示醒目的「N 张」数量提示；点击数量后，浮动工具条应暂时隐藏，各图片槽位应从当前节点向右上方整齐展开；已成功图片的「设为主图」应常驻显示，并在亮色、深色主题及不同图片背景上保持清晰；点击画布空白处应自动收起并恢复工具条。
- 画布多图主图切换：点击「设为主图」后，节点中心和当前最长边应保持不变，仅按新图片比例调整另一条边；自由变形节点应完全保持现有宽高，画布视口及左下角缩放值不应变化。
- 画布多图失败槽位：包括当前主槽位在内的每个失败槽位都应显示「重试」和「删除」；重试只更新当前槽位，已有成功主图时不得抢占主图；删除只移除当前失败槽位并同步更新图片数量。
- 画布多图尺寸调整：子图展开时开始拖动尺寸控制点，应先收起图片组一次，再正常调整根节点尺寸，不应触发 React 循环更新或应用错误页。
- 画布左侧元素列表：点击元素整行应平滑定位并选中对应节点，自动缩放不得超过 100%；有内容的图片元素应显示预览按钮，点击后打开大图弹窗且不触发画布定位。
- 配置与用户偏好：导出 JSON 后应包含渠道、默认模型和生成偏好；在修改当前配置后重新导入该文件，应恢复导出时的设置，错误 JSON 文件应提示格式不正确。配置文件包含 API Key，不应公开分享。
- 本地存储设置：配置页应显示「本地存储」Tab，进入后只读取 `infinite-canvas` 数据库，自动统计 IndexedDB 占用、站点总占用、浏览器配额与使用率，并按对象仓库显示记录数及内容体积；新增或删除图片、音视频、生成记录后点击刷新，数据应同步变化，统计期间页面保持可操作。
- 模型渠道协议：渠道编辑可选择「火山方舟」并自动填入方舟接口地址；任意名称的生图模型应按方舟 JSON 格式提交参考图，任意名称的视频模型应按方舟任务格式提交和查询，不再依赖模型名包含 `doubao`、`seedream` 或 `seedance`；1080p 不应再因模型名包含 `fast` 被禁用，参考视频应允许最大 200MB、总像素 409600-8295044，并继续校验官方宽高、比例和时长限制。
- 图片编辑弹窗：遮罩、切图和裁剪连续滚轮缩放时，图片与遮罩应保持同步且不再闪烁、短暂消失或跳动；遮罩画笔圆心应始终固定在鼠标位置，仅直径随缩放变化，缩放后仍可准确涂抹、拖动切分线和调整裁剪框。
- 本地服务状态中心：配置页的渠道标签应集中列出已配置的本地渠道（ComfyUI）；进入页面和点击重新检查时应显示检查中、在线或离线，在线时显示耗时以及 ComfyUI 版本或模型数量，无法访问时应显示接口错误且 8 秒左右结束等待；云端 API 渠道不应混入此列表。
- 生成任务中心：画布右上角应显示当前画布的生成任务入口和活动数量；任务从等待中进入运行中，成功、失败或取消后显示准确终态；运行中的任务可取消并同步停止对应节点和 ComfyUI 后端任务，任意任务可定位节点，已结束记录可单独删除或批量清除；刷新页面后遗留的活动任务应恢复为已取消，其他画布的任务不应混入。
- 参考素材自动排序编号：连接图片、视频、音频或文本到生成节点后，应按素材节点从上到下、同高度从左到右分别编号，并在参考连线靠近来源处显示完整编号；移动素材节点后编号应自动更新，实际生成与生成前检查应使用同一顺序；配置节点组装提示词中显式插入的 `@` 引用仍按正文出现顺序发送，不被空间排序覆盖。
- 本地素材丢失与重新关联：导入只含节点数据但缺少 IndexedDB 文件的画布，或清除对应本地文件后重新打开画布，右上角应显示缺失数量；列表应区分图片、视频、音频及多图节点中的具体槽位，选择同类型原文件后应恢复内容并保留节点位置、尺寸、其他批量图片和全部连线；选择错误类型应被拒绝，全部修复后警告入口应消失。
