# 无限画布 · ComfyUI 版

一个本地优先的无限画布：在画布上连接图片、视频、音频和文本节点，上传自己的 ComfyUI API 工作流，直接调用本机 ComfyUI 生成图片、视频和音频，不需要每次进入 ComfyUI 手动替换素材或重新连线。

## 已完成功能

### 画布

- 无限画布：创建、移动、缩放、连线、分组、导出与自动保存；图片、视频、音频、文本和生成配置节点。
- 选择与编辑：框选、Shift 追加选择、复制粘贴（也支持粘贴剪贴板文本和图片）、200 步撤销/重做、方向键微调（Shift 加速）。
- 排版辅助：拖动时显示并吸附对齐参考线（按住 Alt 临时关闭）、多选对齐/分布、节点锁定、分组折叠。
- 画布操作：导出画布 PNG、顶栏切换画布、空白处双击创建节点、触屏双指缩放。
- 快捷键教程：画布右上角键盘按钮或画布菜单可打开分组的快捷键说明。
- 独立素材上传：从画布节点菜单直接上传图片、视频或音频；上传的素材会自动归档到「我的资产」（按内容哈希去重）。

### ComfyUI 工作流

- 本地 ComfyUI：通过标准 HTTP 接口连接官方版、源码版、桌面版或任意第三方整合包；`http://127.0.0.1:8188` 只是默认地址。
- 自带工作流：每个工作流对应你从 ComfyUI 导出的 API 格式 JSON，自动识别提示词、时长、比例、兆像素、随机种子、参考槽位和输出节点。
- 动态参考素材：只把画布实际连接的素材传入本次工作流，未使用的参考槽位会自动移除；参考视频的音轨可接到对应视频音频输入。
- 生成前检查：提交前显示最终提示词、模型参数、参考素材顺序、工作流槽位和输出节点，映射缺失或素材超量时阻止提交。
- 节点兼容性检查：读取当前 ComfyUI 已注册的节点类型并与工作流对比，缺少节点时直接列出节点类型。
- 固定调用器：工作流由固定调用器安全执行，任意自定义脚本执行已被移除。
- 后端同步取消：停止画布中的任务时，同时取消 ComfyUI 中对应的排队或运行任务。
- 工作流类型：图片、视频、音频工作流可分别添加，共用同一个 ComfyUI 接口地址。

### 生成与任务

- 图片、视频、音频和文本生成：全部在画布内完成。
- 生成任务中心：画布右上角统一查看、定位、取消和清理等待中、运行中、已完成、失败或已取消的任务。
- 参考自动排序：连接素材按画布位置从上到下、同排从左到右自动编号；提示词中显式插入的引用顺序优先。
- 视频参数：比例选择、自定义宽高、5/10/15 秒和自定义时长。
- 图片编辑：裁剪、旋转角度、蒙版局部重绘、超分和分割。
- 素材重新关联：浏览器本地素材丢失后保留节点与连线，可从画布右上角选择原文件恢复。
- 后台通知：生成完成或失败时可通过浏览器通知提醒。

### 我的资产

- 支持文本、图片、视频和音频资产，视频卡片显示首帧。
- 搜索、标签筛选、排序和创建时间显示。
- 多选批量删除、批量导出、批量加标签；支持拖拽上传和重复文件检测。
- 资产可「插入画布」并跳回来源画布。

### 配置、插件与桌面版

- 配置页：ComfyUI 渠道（本地服务快捷接入）、本地服务状态、本地存储统计和配置导入/导出。
- 渠道配置只保留渠道名称、ComfyUI 接口地址和工作流列表，本地 ComfyUI 不需要 API Key。
- 节点插件系统：可从官方插件注册表安装插件（Markdown、HTML、3D 全景、便利贴等）。
- 源码一键更新：画布可从本仓库 `main` 分支安全快进更新，不会强制覆盖本地修改。
- Windows 桌面版：GitHub Release 提供独立安装程序，并通过同一仓库接收后续版本更新。
- 本地保存：画布、素材和渠道配置默认保存在当前浏览器中。

## Windows 桌面版

普通 Windows 用户可以在 [GitHub Releases](https://github.com/kiligsqsq-ctrl/infinite-canvas-comfyui/releases) 下载最新版本中以 `.exe` 结尾的安装程序。安装后从开始菜单启动即可，不需要另外安装 Git、Bun 或 Node.js。ComfyUI 和模型文件仍由用户自行安装、启动并在画布中填写地址。

应用会根据同一版本发布中的 `latest.yml` 和 `.blockmap` 检查更新。收到新版本提示后按应用提示下载并重启，画布和配置数据会继续保存在本机。桌面版连接本机或局域网 ComfyUI 时会使用只允许私有地址的内置代理，因此无需给 ComfyUI 增加浏览器 CORS 参数；源码安装仍按下文配置 CORS，并使用 Git 更新通道。

安装包暂未配置商业代码签名证书，Windows SmartScreen 可能显示「未知发布者」。请只从本仓库 Releases 下载，并在核对来源后继续安装。

维护者发布版本时，先整理 `CHANGELOG.md`，然后使用版本脚本。当前版本从根目录 `VERSION` 读取，版本依次为 `0.0.1` 至 `0.0.5`、`0.1.0` 至 `0.1.5`、`0.2.0`，以此类推：

```powershell
node scripts/version.mjs next
node scripts/version.mjs bump
$releaseVersion = Get-Content VERSION
node scripts/version.mjs check "v$releaseVersion"
git add -A
git commit -m "release: v$releaseVersion"
git tag "v$releaseVersion"
git push origin main
git push origin "v$releaseVersion"
```

推送格式严格为 `v<主版本>.<次版本>.<补丁版本>` 的 tag 后，Windows 工作流会校验根版本、桌面端与 Web 的版本，并确认 tag 相对最近的合法版本严格递增；随后从干净检出构建桌面包，把 `.exe`、`.blockmap` 和 `latest.yml` 上传到对应的 GitHub Release。本地发版流程不需要手工构建安装包。

## 源码运行前准备

本节及后续命令用于源码开发方式。安装 Windows 桌面版的用户不需要 Git 或 Bun，可以直接跳到「三、启动 ComfyUI」。使用源码方式前，请确认电脑中已经具备：

1. Git。
2. Bun。
3. 任意能够提供标准 HTTP API 的 ComfyUI，例如官方桌面版、官方源码版、便携版或第三方整合包。
4. 能在自己的 ComfyUI 中正常运行的目标工作流，以及该工作流需要的模型、VAE、CLIP、LoRA 和自定义节点。

本仓库只包含画布和调用功能，不包含任何模型文件。画布不读取 ComfyUI 的安装目录，也不依赖任何特定启动器。

## 一、源码方式：下载仓库

```bash
git clone https://github.com/kiligsqsq-ctrl/infinite-canvas-comfyui.git
cd infinite-canvas-comfyui
cd web
```

也可以在 GitHub 仓库页面点击 `Code` → `Download ZIP`，解压后进入其中的 `web` 文件夹。

## 二、源码方式：安装并启动无限画布

第一次运行时，在 `web` 文件夹中执行：

```bash
bun install
bun run dev
```

看到下面的地址后，在浏览器中打开：

```text
http://localhost:3000
```

以后再次使用时，进入 `web` 文件夹执行：

```bash
bun run dev
```

运行画布的命令窗口需要保持打开。

## 三、启动 ComfyUI

在你自己的 ComfyUI 启动参数中加入：

```text
--enable-cors-header http://localhost:3000
```

源码版或命令行版也可以这样启动：

```bash
python main.py --enable-cors-header http://localhost:3000
```

然后确认自己的 ComfyUI 地址能够在浏览器中打开，例如：

```text
http://127.0.0.1:8188
```

`8188` 只是 ComfyUI 常见的默认端口，不是强制端口。如果你的 ComfyUI 使用其他端口或局域网地址，后面的接口地址填写实际地址即可。使用浏览器源码版时需要允许来自 `http://localhost:3000` 的跨域访问；Windows 桌面版不需要这项启动参数。

## 四、在无限画布中配置 ComfyUI

源码方式打开 `http://localhost:3000`；Windows 桌面版从开始菜单启动。进入画布后：

1. 点击右上角「配置」。
2. 打开「渠道」页面。
3. 在「本地服务快捷接入」中点击「ComfyUI 工作流」。
4. 系统会自动填入示例地址 `http://127.0.0.1:8188`；点击「添加工作流」。
5. 输入工作流名称（例如 image、video、audio），并选择它的类型：图片、视频或音频。
6. 点击该工作流右侧的「上传 API 工作流」，导入你从自己的 ComfyUI 导出的 API 格式 JSON。
7. 检查自动识别的提示词、时长、比例、参考槽位和输出节点，再点击「检查当前 ComfyUI」。缺少节点时会直接列出节点类型。
8. 保存工作流映射，再点击渠道右上角「保存」。以后生成时会使用这个本地工作流，不要求和仓库作者拥有完全相同的工作流。
9. 图片、视频、音频要分别添加工作流；它们共用同一个 ComfyUI 地址，生成时选哪个工作流就调用哪一份 JSON。本地 ComfyUI 默认不需要 API Key；如果端口不是 `8188`，只修改「接口地址」中的端口。

如果有旧版本保存的云端 API 渠道，仍可在渠道列表中编辑或删除；新版本不再提供新增云端 API 渠道的入口。

如果没有看到「本地服务快捷接入」，请重新启动画布，然后在浏览器中按 `Ctrl + F5` 强制刷新。

## 五、一键更新

页面右上角的云下载按钮用于一键更新画布。源码开发模式会固定从 `kiligsqsq-ctrl/infinite-canvas-comfyui` 仓库的 `main` 分支获取最新版，并在完成后自动刷新网页；Windows 桌面版则检查 GitHub Releases，下载完成后提示重启安装。

下面三个条件只适用于源码方式的一键更新：

- 使用 `git clone` 安装，而不是下载 ZIP。
- 当前位于 `main` 分支。
- 本地源码没有未提交或未跟踪的文件。

本地与仓库版本发生分叉时，更新会安全停止，不会强制覆盖文件。

## 六、在画布中生成内容

1. 把需要使用的图片、视频和音频添加到画布。
2. 创建生成配置节点，选择你上传了工作流的模型。
3. 把本次需要参考的素材连接到生成配置节点。
4. 输入提示词并开始生成。
5. 画布会自动把素材上传到 ComfyUI，运行工作流并等待结果。
6. 生成完成后，结果会自动添加回画布。

参考素材按照画布传入顺序排列：第一张连接的图片对应第一个图片参考槽位，第一个视频对应第一个视频参考槽位，第一个独立音频对应第一个音频参考槽位。

不需要使用的素材不要连接，也不需要打开 ComfyUI 手动修改工作流。如果你上传的工作流准备了多个参考槽位，画布只会填入本次实际连接的素材并移除未使用的加载节点；实际参考数量仍需遵守模型和当前工作流的限制。

## 常见问题

### 无法连接 ComfyUI

确认以下三项：

- ComfyUI 已经启动。
- 浏览器能够打开 `http://127.0.0.1:8188`。
- 使用浏览器源码版时，ComfyUI 启动参数中已经加入 `--enable-cors-header http://localhost:3000`；Windows 桌面版无需添加。

官方版、源码版和整合包使用的是同一套连接逻辑。画布只访问 `/system_stats`、`/object_info`、`/upload/image`、`/prompt`、`/history`、`/view` 和取消任务等标准接口，不识别也不要求某个整合包。

画布顶栏会显示 ComfyUI 在线状态（在线 / 离线 / 检测中 / 未配置），离线时点击状态可跳转到配置页检查。

### 工作流兼容性检查提示缺少节点

「检查当前 ComfyUI」会读取当前实例实际注册的节点类型，并和上传的 API 工作流逐项对比。先在 ComfyUI 中安装提示的自定义节点并重启，再重新检查。

节点检查无法确认磁盘上的模型文件。模型、VAE、CLIP、LoRA 等仍需在 ComfyUI 中加载并先成功运行一次工作流。

### 打开画布后没有 ComfyUI 工作流预设

关闭旧的画布进程，在 `web` 文件夹重新执行：

```bash
bun run dev
```

然后在浏览器中按 `Ctrl + F5`。

### 别人安装后不能生成

不要求对方使用秋叶整合包，也不要求 ComfyUI 安装路径相同。对方只需启动任意兼容的 ComfyUI、安装自己工作流所需的节点和模型，然后在画布中上传自己的 API 格式工作流并完成映射。
